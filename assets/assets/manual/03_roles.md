# الأدوار والصلاحيات

*ستة أدوار، ومدير المكتب هو المسؤول الأول والأخير. كل الصلاحيات مفروضة في قاعدة البيانات.*

## الأدوار الستة

| الدور | ما يستطيعه |
| --- | --- |
| **مدير المكتب** | كل الصلاحيات، وتعديلاته تُنفَّذ مباشرة دون طلب اعتماد. ينفرد بـ: اعتماد طلبات النماذج الحساسة، والمستخدمين وأدوارهم، وصلاحيات النماذج، والحذف، وفك الدمج، والإعدادات، والتخصيص، ومساعد Claude، وسجل التدقيق الكامل. |
| **موظف مكتب المدير** | إضافة العقود وتعديل بياناتها وأعمالها، وتحديث كل النماذج (الحساسة منها بطلب اعتماد)، والبيانات المالية والمستخلصات بصفته مختصاً بنموذج «أمر بالتعاقد»، وتحرير تحليل SWOT، واعتماد الدروس المستفادة. |
| **رئيس قسم** | نماذج اختصاص قسمه فقط، والبرنامج الزمني للعقود التي يشرف عليها قسمه، وتحديث إنجاز إجراءات قسمه في خطة SWOT. |
| **مكتب العقود والتوريدات والمستخلصات** | نماذج التعاقد والمستخلصات وإقفال العقد، والبيانات المالية، ورقم العقد، وأعمال العقد ودمجها، والبت في طلبات التغيير. |
| **مكتب التخطيط والتقييم وضمان الجودة** | اطلاع كامل وتصدير، وتسجيل ملاحظات التقييم والجودة، وتحديث النماذج المسندة إليه (مثل تكليف مهندس المتابعة). |
| **CISO** (مسؤول الأمن السيبراني) | قسم «الأمن السيبراني» كاملاً: لوحة الأمن والوضع الأمني والأنماط غير المعتادة والهويات والصلاحيات والجلسات والأجهزة ونشاط البيانات وسجل التدقيق كاملاً والبيانات الوصفية للمراسلات والحوادث (الفصل 27)، واطلاع على كل الأقسام. وإجراءاته: إنهاء الجلسات، والإخراج من الأجهزة، وقفل الدخول، وحظر الأجهزة، وتعليق الصلاحيات الدقيقة، وقفل المحادثات، والتجميد الطارئ للمنظومة. لا يكتب في بيانات العمل ولا يغيّر الأدوار، ولا يتخذ إجراءً على حساب المدير، وكل إجراء مسجّل. |

## من يملك كل عملية

| العملية | من يملكها |
| --- | --- |
| تحديث حالة نموذج في الدورة المستندية | الجهات المسندة إليها النموذج في «صلاحيات النماذج»، والمدير دائماً. النموذج الحساس من غير المدير يصبح طلب اعتماد. |
| البيانات المالية والمستخلصات وأوامر التغيير والدفعات | من يختص بنموذج «أمر بالتعاقد» (حالياً موظفو مكتب المدير ومكتب العقود)، والمدير. المستخلص المدفوع لا يعدّله ولا يحذفه إلا المدير. |
| سجل المخاطر ومراجعاته، والتقدم الدوري، والمشاكل، والتأخيرات، والتغييرات، والدروس، وتقييم الشركات | كل الأعضاء المفعّلين عدا CISO (له الاطلاع). |
| البرنامج الزمني للعقد | المدير، وموظفو مكتبه، ومكتب العقود، ورئيس القسم المشرف على العقد. |
| البت في طلبات التغيير (اعتماد أو رفض) وتعديل ما بُتّ فيه | من يختص بمالية العقد، والمدير. |
| اعتماد الدروس المستفادة وتسجيل تطبيقها | المدير وموظفو مكتبه. |
| معايير مستويات الخطر وقوائمه، وإعدادات متابعة المشاريع | المدير وحده. |
| حذف خطر أو مراجعة أو أي سجل متابعة أو عقد | المدير وحده، ويبقى أثر الحذف في سجل التدقيق. |
| تحليل SWOT: العوامل والاستراتيجيات والإجراءات | المدير وموظفو مكتبه. ورئيس القسم يحدّث إنجاز الإجراءات المسندة إلى قسمه أو إلى «جميع الأقسام». |
| المقايسات: الإضافة والإصدارات والملفات | المدير، وموظفو مكتبه، ومكتب العقود، ورئيسا قسمي الشؤون الفنية والمطابقة والاستلام. |
| المراسلات: الوارد والصادر والداخلي | كل الأعضاء المفعّلين عدا CISO (له الاطلاع). |
| التصاميم: الإضافة والإصدارات والصور | المدير، وموظفو مكتبه، ورئيسا قسمي الشؤون الفنية والترميم، ورئيس القسم المشرف على العقد لتصاميم عقده. |
| التقارير اليومية للإشراف | المدير، وموظفو مكتبه، ورئيس القسم المشرف على العقد. والاطلاع عليها وتسجيل الملاحظة للمدير وحده. |
| حذف إصدار أو ملف أو تقرير يومي | المدير، أو من أضافه خلال 24 ساعة من إضافته. وحذف المستند كله للمدير وحده. |
| سجل المباني التاريخية وتقييمات الحالة | المدير، وموظفو مكتبه، ورئيس قسم الترميم، ومستخدمو وحدة «الترميم والمباني التاريخية» (الفصل 19). |
| الخطط، والتدقيقات، والتكليفات | المدير، وموظفو مكتبه، ودور مكتب التخطيط وضمان الجودة، ومستخدمو كل قسم من أقسامه الثلاثة (الفصل 20). |
| جولات التفتيش والحوادث والمخالفات | المدير، وموظفو مكتبه، ومستخدمو «مكتب السلامة المهنية» (الفصل 21). |
| محاضر الاستلام والملاحظات، والاختبارات وحالات عدم المطابقة | المدير، وموظفو مكتبه، ورئيس قسم المطابقة والاستلام، ومستخدمو كل وحدة (الفصل 22). |
| اعتماد المواد | المدير، وموظفو مكتبه، ورئيس قسم الشؤون الفنية، ومستخدمو «قسم الشؤون الفنية» (الفصل 17). |
| حذف سجل وحدة أو مرفقه | المدير ورئيس الوحدة، أو من أضافه خلال 24 ساعة. |
| إسناد المستخدم إلى وحدة، عضواً أو رئيساً | المدير وحده (الفصل 23). |
| التصدير والطباعة ومكتبة الوسائط | كل الأعضاء المفعّلين، لما يطّلعون عليه. وكل استخراج يُسجَّل في التدقيق (الفصل 25). |
| قوالب الطباعة العامة والقالب الافتراضي | المدير وموظفو مكتبه. والقوالب الخاصة لكل مستخدم (الفصل 25). |

| المراسلات الداخلية: المحادثات الخاصة والمجموعات | كل الأعضاء المفعّلين. والقنوات ينشئها المدير ويحدد جمهورها (الفصل 26). |
| قفل محادثة والاطلاع على البيانات الوصفية للمراسلات | المدير ومسؤول الأمن السيبراني، دون نصوص الرسائل (الفصل 27). |
| صيغ الأرقام الإشارية وضبط تسلسلها | المدير وحده. وسجل الأرقام لكل الأعضاء (الفصل 25). |
| الصلاحيات الدقيقة لمستخدم | يمنحها المدير ويسحبها، ويعلّقها مسؤول الأمن عند الحاجة. |
| تخصيص أسماء الأقسام والصفحات وترتيبها وإخفائها | المدير وحده (الفصل 23). |

توزيع النماذج على الجهات، وتحديد أيها حساس، قابلان للتعديل من «لوحة التحكم ← الصلاحيات» دون برمجة.

**أين تُفرض الصلاحيات:** لا يكتب أي مستخدم في جداول قاعدة البيانات مباشرة. كل إضافة أو تعديل أو حذف، من إنشاء العقد إلى تغيير المستخدم اسمه، يمر بدالة في قاعدة البيانات تتحقق من صلاحية صاحبه بالجدول أعلاه، ثم تسجّله في سجل التدقيق. فلا تتجاوز الصلاحيات نسخةٌ قديمة من التطبيق ولا طلبٌ يُرسل من خارجه (الترحيل 26).

## الصلاحيات الدقيقة

يمنح المدير مستخدماً صلاحية الكتابة في **بند واحد** دون القسم كله، فوق صلاحيات دوره. من «لوحة التحكم ← المستخدمون والأدوار» افتح المستخدم، ثم «الصلاحيات الدقيقة ← تعديل»، واختر:

| النطاق | ما يتيحه |
| --- | --- |
| نموذج من نماذج الدورة المستندية | تحديث حالة هذا النموذج وحده في كل العقود (والحساس منه بطلب اعتماد كالمعتاد). ونموذج «أمر بالتعاقد» يشمل البيانات المالية للعقد وأعماله، والنموذج المرتبط بمهندس يشمل تكليف المهندس |
| المقايسات أو المراسلات أو التصاميم | إضافة المستندات وإصداراتها وملفاتها في هذا النوع وحده |
| التقارير اليومية للمواقع | كتابة تقارير الإشراف لكل العقود الجارية |
| نوع سجل في وحدة | مثل «حالة عدم مطابقة» وحدها دون باقي سجلات ضبط الجودة: إضافتها وتعديلها ورفع مرفقاتها، وحذف ما أضافه خلال 24 ساعة |
| تحليل SWOT | تحرير العوامل والاستراتيجيات والإجراءات |

- لا تُمنح صلاحيات دقيقة للمدير (له كل شيء) ولا لمسؤول الأمن (يطّلع ولا يكتب)، والحد الأعلى 80 صلاحية للمستخدم.
- التجميد يوقفها كباقي الصلاحيات، وتتوقف إن أُوقف الحساب أو قُفل.
- كل منح وسحب في سجل التدقيق بما أُضيف وما أُزيل، وتظهر صلاحيات كل مستخدم لمسؤول الأمن في «الهويات والصلاحيات» (الفصل 27).

## الوحدات

إضافة إلى الدور، يُسند المدير المستخدم إلى وحدة من ثماني وحدات، عضواً أو رئيساً: الترميم والمباني التاريخية، وقسم التخطيط، وقسم ضمان الجودة، وقسم المتابعة، ومكتب السلامة المهنية، ووحدة الاستلام، ووحدة ضبط الجودة، وقسم الشؤون الفنية.

- **عضو الوحدة** يكتب في سجلاتها، ويطّلع على سجلات الوحدات الأخرى.
- **رئيس الوحدة** يكتب ويحذف أي سجل أو مرفق في وحدته.
- الوحدة لا تغيّر الدور: موظف مكتب المدير المُسنَد إلى وحدة يبقى بكل صلاحيات دوره.
- لا تُسند وحدة إلى المدير، فهو رئيس كل الوحدات، ولا إلى CISO لأنه يطّلع ولا يكتب.
