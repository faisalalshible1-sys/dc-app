# ملحق: مرجع سريع للمعادلات

*كل معادلات المنظومة في جدول واحد، مع رقم الفصل الذي يشرحها.*

| المؤشر | المعادلة | الفصل |
| --- | --- | --- |
| نسبة إنجاز العقد | المكتملة ÷ (النشطة − لا ينطبق) | 5 |
| إنجاز الدورة (الرئيسية) | متوسط بسيط لنسب العقود | 5 |
| القيمة بعد التغيير | التعاقدية + (الزيادات − التخفيضات) | 7 |
| صافي المستخلص | قيمة الأعمال − كل الاستقطاعات | 7 |
| الاسترداد المقترح | الأصغر من (قيمة الأعمال × النسبة) والرصيد | 7 |
| الضمان الابتدائي / النهائي | المنفذ × 5% / المنفذ × 2% | 7 |
| المدفوع الكلي | مدفوع المستخلصات + الدفعة المقدمة المصروفة + الدفعات اليدوية | 7 |
| المتبقي من الأعمال / للدفع | بعد التغيير − المنفذ / بعد التغيير − المدفوع الكلي | 7 |
| درجة الخطر | الاحتمالية × التأثير | 9 |
| «مرتفع» | الدرجة 13 فأكثر (المستويان الأعليان) | 9 |
| الخفض المستهدف / المحقق | 1 − المستهدفة ÷ الأولية / 1 − الحالية ÷ الأولية | 9، 10 |
| المراجعة القادمة | آخر مراجعة (أو التسجيل) + دورية المستوى الحالي | 10 |
| متابعة متأخرة | الموعد قبل تاريخ الإسناد، أو انقضاء الموعد المستهدف والتنفيذ < 100% | 10 |
| نسبة الإغلاق | المغلقة ÷ الإجمالي | 11 |
| النهاية المعدّلة | النهاية التعاقدية + تمديدات التغييرات والتأخيرات المعتمدة | 12 |
| SPI | الفعلي ÷ المخطط | 12 |
| السرعة الحالية / المطلوبة | Δالفعلي ÷ الأيام × 7 / (1 − الفعلي) ÷ الأيام للنهاية × 7 | 12 |
| تاريخ الإنجاز المتوقع | آخر قياس + (1 − الفعلي) ÷ السرعة × 7 | 12 |
| SPI المحفظة | الفعلي الموزون بالقيمة ÷ المخطط الموزون | 12 |
| أيام التأخير | (النهاية أو تاريخ الإسناد) − البداية | 13 |
| السبب الحيوي (باريتو) | التراكمية قبله < 80% | 13 |
| نسبة التغييرات | الأثر المالي المعتمد ÷ قيمة العقد (الحد 10%) | 13 |
| الدرجة المركّبة للشركة | Σ(المكوّن × الوزن) ÷ Σ الأوزان المتاحة | 14 |
| أولوية العامل | الأهمية × الاستعجال | 16 |
| IFE / EFE | Σ(الأهمية ÷ مجموع أهمية الفئة × التقييم) | 16 |
| خلية IE | الصف × 3 + العمود | 16 |
| الإنجاز المخطط للإجراء | (اليوم − البدء) ÷ (الانتهاء − البدء) | 16 |
| رقم الإصدار الجديد للمستند | أكبر رقم إصدار + 1 (لا يُعاد رقم محذوف) | 17 |
| المراسلة المتأخرة | بانتظار رد، وموعد الرد قبل اليوم | 17 |
| إجمالي المقايسات المعتمدة | Σ القيمة الإجمالية للمعتمدة | 17 |
| تصغير الصورة وضغطها | البعد الأكبر ≤ 2400 بكسل؛ JPG 82% إن صُغّرت أو تجاوزت 1.5 م.ب | 17 |
| نسبة استخدام المساحة | (المستندات والتقارير + الإصدارات) ÷ حد الخطة | 17 |
| تقارير اليوم | العقود الجارية التي لها تقرير اليوم ÷ العقود الجارية | 18 |
| تغطية التقارير للعقد | أيام العمل التي فيها تقرير ÷ أيام العمل (دون الجمعة افتراضياً) | 18 |
| السجل المتأخر (الوحدات) | له موعد، والموعد قبل اليوم، ولم يُغلق | 19 |
| بحالة سيئة أو خطرة | المباني التي حالتها الإنشائية في بطاقتها سيئة أو خطرة | 19 |
| متوسط إنجاز الخطط | متوسط نسب الخطط قيد التنفيذ التي لها نسبة | 20 |
| الإنجاز في الموعد | المنجزة في موعدها أو قبله ÷ المنجزة التي لها موعد | 20 |
| أيام بلا حوادث | اليوم − تاريخ آخر حادث غير وشيك | 21 |
| متوسط الالتزام | متوسط نسب التزام جولات الشهر | 21 |
| نسبة المطابقة | المطابقة ÷ (المطابقة + غير المطابقة) | 22 |
| إجمالي بند المقايسة | الكمية × سعر الوحدة من اللائحة (الكمية الفارغة صفر) | 28 |
| المخطط للبند | (تاريخ الإسناد − البداية المخططة) ÷ (النهاية − البداية)، محصوراً بين 0 و100% | 29 |
| انحراف البند | الفعلي − المخطط (نقطة)، وبالأيام: الفعلي × المدة − الأيام المنقضية | 29 |
| الإنجاز الكلي للمشروع | Σ(وزن البند × إنجازه) ÷ Σ الأوزان (الوزن الفارغ = متوسط المسجلة) | 29 |

## مصطلحات

|   |   |
| --- | --- |
| **تاريخ الإسناد** | التاريخ الذي تُحسب عليه مؤشرات المتابعة، وهو اليوم ما لم يُثبَّت. |
| **المستخلص المحتسب** | مستخلص حالته معتمد أو محال للصرف أو مدفوع، فيدخل المنفذ والمجاميع. |
| **الخطر النشط** | كل خطر حالته غير «مغلق». |
| **التقييم الأولي / الحالي / المستهدف** | عند التسجيل / من آخر مراجعة / المتوقع بعد تنفيذ الإجراءات. |
| **SPI** | Schedule Performance Index: مؤشر أداء الجدول الزمني، أي نسبة ما أُنجز فعلاً إلى ما كان مخططاً حتى تاريخ القياس. |
| **IFE / EFE / IE** | مصفوفة تقييم العوامل الداخلية / الخارجية / المصفوفة الداخلية-الخارجية. |
| **TOWS** | مصفوفة ربط العوامل الداخلية بالخارجية لصياغة الاستراتيجيات. |
| **EOT** | Extension of Time: تمديد المدة. |
| **CISO** | مسؤول أمن المعلومات. |
