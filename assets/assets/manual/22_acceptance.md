# المطابقة والاستلام

*وحدتان في قائمة واحدة: وحدة الاستلام لمحاضر الاستلام وقوائم الملاحظات، ووحدة ضبط الجودة للاختبارات وحالات عدم المطابقة. وقواعد السجلات المشتركة في الفصل 19.*

## صفحات القسم

| الصفحة | ما فيها |
| --- | --- |
| **لوحة القسم** | مؤشرات الوحدتين ومستخدموهما، والمتأخر فيهما، وأحدث السجلات |
| **وحدة الاستلام** | مبدّل بين «محاضر الاستلام» و«قوائم الملاحظات» |
| **وحدة ضبط الجودة** | مبدّل بين «الاختبارات» و«حالات عدم المطابقة» |

الأرقام على عناصر القائمة: ملاحظات الاستلام التي تجاوزت موعد إصلاحها، وحالات عدم المطابقة التي تجاوزت موعد الإجراء التصحيحي.

اعتماد المواد في قسم الشؤون الفنية (الفصل 17).

## من يكتب في هذا القسم

المدير، وموظفو مكتب المدير، ورئيس قسم المطابقة والاستلام في الوحدتين، والمستخدمون المُسنَدون إلى كل وحدة في وحدتهم. ورئيس قسم المطابقة والاستلام رئيس للوحدتين، إضافة إلى رئيس كل وحدة المُسنَد إليه.

| الحقل | الوصف |
| --- | --- |
| موضوع المحضر | مطلوب |
| رقم المحضر | اختياري |
| تاريخ الاستلام | مطلوب، ويجوز أن يكون مستقبلياً للمحضر المجدول |
| العقد | مطلوب |
| الحالة | مجدول · مقبول · مقبول بملاحظات · مرفوض. والحالات المغلقة الثلاث الأخيرة |

### قائمة الملاحظات

كل ملاحظة تتبع محضر استلام وتأخذ عقده، وتُضاف من صفحة المحضر (زر «إضافة ملاحظة استلام»).

| الحقل | الوصف |
| --- | --- |
| الملاحظة | مطلوب |
| المحضر | مطلوب |
| تاريخ الرصد | مطلوب |
| موعد الإصلاح | الموعد |
| الحالة | قائمة · أُصلحت. والحالة المغلقة «أُصلحت» |
| المسؤول عن الإصلاح | نص |
| الموقع في المبنى | نص |

في صفحة المحضر قسم «قوائم الملاحظات» بعدد الملاحظات وما بقي منها قائماً. وفي قائمة المحاضر تظهر على كل محضر شارة بعدد ملاحظاته القائمة.

## وحدة ضبط الجودة

### الاختبار

| الحقل | الوصف |
| --- | --- |
| الاختبار | مطلوب، مثل «مقاومة مكعبات الخرسانة 28 يوماً» |
| رقم التقرير | رقم تقرير المختبر |
| تاريخ الاختبار | مطلوب |
| العقد | مطلوب |
| الحالة | بانتظار النتيجة · مطابق · غير مطابق. والحالتان المغلقتان «مطابق» و«غير مطابق» |
| نوع الاختبار | خرسانة · تربة · حديد تسليح · أسفلت · طوب ومباني · أخرى |
| المختبر | نص |
| العينة وموقعها، والمواصفة | نص |
| القيمة المطلوبة، والنتيجة، ووحدة القياس | نص، مثل 25 و31.5 وMPa |

حالة الاختبار يحددها مهندس الوحدة بمقارنة النتيجة بالقيمة المطلوبة، ولا تُحسب تلقائياً لأن طريقة المقارنة تختلف بين الاختبارات.

### حالات عدم المطابقة

تُضاف من صفحة الاختبار الذي كشفها (فترتبط به وتأخذ عقده)، أو مستقلة من صفحة الوحدة.

| الحقل | الوصف |
| --- | --- |
| وصف عدم المطابقة | مطلوب |
| تاريخ الرصد | مطلوب |
| موعد الإجراء التصحيحي | الموعد |
| الحالة | مفتوحة · قيد المعالجة · مغلقة. والحالة المغلقة «مغلقة» |
| الدرجة | بسيطة · جسيمة · حرجة |
| المسؤول عن المعالجة | نص |
| الاختبار | اختياري: الاختبار غير المطابق الذي كشفها |
| المتطلب المخالف | نص |
| السبب الجذري، والإجراء التصحيحي، والتحقق من فعالية الإجراء | نص طويل |

## مؤشرات القسم

:::formula معادلة: وحدة الاستلام
**محاضر مجدولة** = المحاضر التي حالتها «مجدول»

**استلامات هذا العام** = المحاضر التي تاريخها في السنة الحالية وحالتها غير «مجدول»

**ملاحظات قائمة** = ملاحظات الاستلام غير المغلقة، وتحتها عدد ما تجاوز موعد إصلاحه ولم يُغلق
:::

:::formula معادلة: وحدة ضبط الجودة
**اختبارات هذا الشهر** = الاختبارات التي تاريخها في الشهر الحالي، وتحتها عدد كل الاختبارات «بانتظار النتيجة»

**نسبة المطابقة** = الاختبارات «المطابقة» ÷ (المطابقة + غير المطابقة)، لكل الاختبارات المسجّلة. ولا تدخل فيها الاختبارات بانتظار النتيجة. ويظهر «—» إن لم توجد نتائج

**عدم مطابقة مفتوحة** = حالات عدم المطابقة غير المغلقة (مفتوحة أو قيد المعالجة)، وتحتها عدد الجسيمة والحرجة منها

**إجراءات متأخرة** = حالات عدم المطابقة المتأخرة: موعد الإجراء التصحيحي قبل اليوم ولم تُغلق
:::

:::example مثال محلول
في الوحدة 23 اختباراً: 18 مطابقاً، و2 غير مطابقين، و3 بانتظار النتيجة.

نسبة المطابقة = 18 ÷ (18 + 2) = **90%**. والاختبارات الثلاثة المعلقة لا تدخل في النسبة.
:::

وتعرض بطاقة القسم في الشاشة الرئيسية: ملاحظات الاستلام القائمة، والاختبارات بانتظار النتيجة، وحالات عدم المطابقة المفتوحة.
