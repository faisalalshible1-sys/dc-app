# خطوط الطباعة والتصدير

خطوط تُضمَّن في ملفات PDF التي تُستخرج من المنظومة:

- `NotoNaskhArabic-*.ttf` و`NotoKufiArabic-*.ttf`: من مشروع Noto (https://github.com/notofonts/arabic).
- `ArLatSans-*.ttf`: Noto Sans Arabic مدمجاً معه Noto Sans للحروف اللاتينية والرموز (الخط نفسه المستعمل في اللقطات البصرية).

الخطوط كلها مرخّصة بـ SIL Open Font License 1.1 (https://openfontlicense.org)، ونص الترخيص وحقوق النشر مضمّنان في كل ملف خط.
