# لوحة القيادة والتنبيهات والتقرير الدوري

*لوحة القيادة نقطة البداية الأسبوعية: مؤشرات المحفظة، وتنبيهات بالإجراء المطلوب ورابط المرجع، وملخص أداء المشاريع.*

## المؤشرات الواحد والعشرون

| المؤشر | طريقة الحساب |
| --- | --- |
| إجمالي المشاريع | كل العقود القائمة، مع مجموع قيمها |
| المشاريع الجارية | الوضع التشغيلي «جارٍ»، مع عدد «لم يبدأ» |
| مشاريع متأخرة | تأخر بسيط + متأخر حرج، ومنها الحرج |
| مشاريع منجزة | مؤشرها «منجز»، مع عدد المتقدمة |
| الإنجاز الفعلي / المخطط (موزون) | الفصل 12، للمشاريع الجارية |
| مؤشر أداء المحفظة SPI | الفعلي الموزون ÷ المخطط الموزون |
| مخاطر نشطة | غير المغلقة، مع عدد المسجلة |
| مخاطر مرتفعة حالياً | نشطة بدرجة حالية 13 فأكثر، مع عدد المتصاعدة |
| مشاكل مفتوحة | غير المغلقة، مع عدد المتأخرة عن موعد الحل |
| أيام التأخير المسجلة | مجموع أيام كل الأحداث، ومنها على المسار الحرج |
| التمديدات المعتمدة | مجموع التمديد المعتمد لكل المشاريع، مع عدد الأحداث القائمة |
| التغييرات المعتمدة | مجموع الأثر المالي المعتمد، مع عددها |
| نسبة التغييرات من العقود | المعتمد ÷ مجموع قيم العقود، مع عدد ما ينتظر البت |
| الدروس الموثقة / بانتظار الاعتماد | كل الدروس والمُطبَّق منها / المقترحة والمعتمدة |
| متوسط التقييم الميداني | متوسط متوسطات كل التقييمات (من 5) |
| الشركة الأعلى / الأدنى أداءً | الأولى والأخيرة بالدرجة المركّبة (الأدنى تظهر إذا وُجدت شركتان بدرجة) |
| مراجعات مخاطر متأخرة | حالة متابعة «متأخرة»، مع «مستحقة قريباً» |
| مشاريع دون تحديث للتقدم | جارية بلا قياس أو آخر قياس قبل أكثر من 10 أيام |

كل تنبيه يحمل عدده ورابطاً إلى الصفحة المعنية، والرقم على «لوحة القيادة» في القائمة هو عدد التنبيهات التي عددها أكبر من صفر.

## التقرير الدوري

- **الفترة:** أسبوعي من الأحد إلى السبت للأسبوع الذي يقع فيه التاريخ المختار، أو شهري من أول الشهر إلى آخره.
- **رقم الأسبوع:** الأسابيع تبدأ بالأحد، والأسبوع الأول هو الذي فيه 1 يناير. مثال: التاريخ 2026/11/14 يقع في الأسبوع 46 (من 2026/11/08 إلى 2026/11/14).
- **المشاريع الجارية خلال الفترة:** بدأت قبل نهاية الفترة، وليست «لم يبدأ» ولا «موقوف»، ولم يبلغ إنجازها 100% قبل بدايتها. ويشمل ذلك ما اكتمل خلال الفترة نفسها.

:::formula معادلة: صف كل مشروع في التقرير
**المخطط والفعلي في نهاية الفترة** = من آخر قياس في نهاية الفترة أو قبلها

**الفعلي في بداية الفترة** = من آخر قياس قبل أول يوم فيها (صفر إن لم يوجد)

**التقدم خلال الفترة** = الفعلي في النهاية − الفعلي في البداية

**الانحراف** = الفعلي − المخطط · **SPI** = الفعلي ÷ المخطط · ثم مؤشر الأداء بالحدود نفسها

**مؤشرات الفترة الموزونة** = متوسطات موزونة بقيمة العقد للمشاريع الجارية خلال الفترة
:::

ويعدّ التقرير ما جرى خلال الفترة: المخاطر الجديدة والمغلقة، والمراجعات المنفذة، والمشاكل الجديدة والمغلقة، وأحداث التأخير التي بدأت، والتغييرات المقدمة والمعتمدة وقيمتها، والدروس الموثقة، والتقييمات المنفذة. ويعرض الوضع الحالي: المخاطر المرتفعة، والمشاكل المتأخرة، والأحداث القائمة. ثم أعلى 5 مخاطر نشطة بالدرجة الحالية، وأكثر 5 مشاكل تأخراً عن موعدها، وملاحظات المكتب. ويُصدَّر إلى Excel.

وفي الصفحة نفسها جدول التقدير، وقوائم أنواع المشاريع، وأسباب التأخير، وأنواع التغييرات وأسبابها، وآليات تعميم الدروس، والأقسام.

## لوحة العرض والتصدير

«لوحة العرض» صفحة تنفيذية واحدة للعرض التقديمي والطباعة: 8 مؤشرات، وجدول المشاريع بأسمائها المختصرة، وأبرز التنبيهات، وأعلى المخاطر، وثلاثة رسوم (التأخير لكل مشروع، وأيام التأخير حسب السبب، والمخاطر حسب المستوى عند التسجيل مقابل الحالي)، مع زر «حفظ صورة». ومن «لوحة القيادة» يُصدَّر القسم كاملاً إلى Excel.
